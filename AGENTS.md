# Agent Workspace Instructions

## UI Styling & Design Rules
1. **No Pill Badges:** Never use pill badges or `rounded-full` text badges across any page.
2. **Universal Corner Radius:** Use `rounded-2xl` (`16px`) for all curved corners throughout the project (cards, containers, buttons, dialogs, inputs). Do not use `rounded-3xl`, `rounded-xl`, `rounded-lg`, `rounded-md`, or `rounded-sm`.
3. **Brand Blue:** Primary blue is strictly `#0056D2`, hover blue is `#0044a8`.
4. **Typography:** Headings use `Plus Jakarta Sans` (`--font-heading`), body uses `Inter` (`--font-sans`). Nav bar links use ALL CAPS and bold formatting.
